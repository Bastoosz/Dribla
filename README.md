# ⚽ Dribla

Plataforma completa para gestão de escolinhas de futebol.

## 🚀 Tecnologias

- **Next.js 16** + **React 18** + **TypeScript**
- **Supabase** (Auth + Database)
- **Resend** (Email)
- **Tailwind CSS**

## ✨ Funcionalidades

- Gestão de alunos e mensalidades
- Dashboard financeiro em tempo real
- Envio automático de cobranças por email
- Geração de relatórios PDF
- 3 planos de assinatura (Free, VIP, Premium)

## 🎭 Modo Demonstração

O projeto inclui um **modo demo** para facilitar testes e apresentações:

- Configure `DEMO_MODE=true` nas variáveis de ambiente da Vercel
- Os emails serão simulados (não enviados de verdade)
- Perfeito para demonstrações, portfólio e LinkedIn
- Em produção real, remova `DEMO_MODE` ou configure `DEMO_MODE=false`
